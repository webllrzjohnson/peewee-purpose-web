# peewee-purpose-web Project Rules

This is a professional website for Purposeful CPR, built with TanStack Start and synchronized with Lovable.

## Workspace Defaults
- Path: `D:\Factory\peewee-purpose-web`.
- Follow the general Factory Workspace rules defined in the root `.hermes.md`.

## Technical Stack
- **Framework**: TanStack Start (React 19, TanStack Router, Nitro).
- **Styling**: Tailwind CSS v4.
- **Build Tool**: Vite.
- **Package Manager**: Bun/npm.

## Verification Expectations
Before calling work complete, run:
- `npm run build` (Ensure the production build succeeds).
- `npm run lint` (Ensure no linting errors).

## Deployment & Approval
- This project is connected to Lovable.
- Do not push to `main` or modify Git history (rebasing/amending) without explicit approval, as it may disrupt the Lovable synchronization.
- All changes must be verified locally before being pushed to the connected branch.

## Final Response Format
Use the concise shipped-change summary:
1. What changed
2. Files changed
3. Commands run / verification result
4. Risks or notes
5. Recommended next step
