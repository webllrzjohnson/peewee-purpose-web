# peewee-purpose-web Project Rules

This is a professional website for Purposeful CPR, built with TanStack Start and synchronized with Lovable.

## Project Defaults

- Path: `D:\Factory\peewee-purpose-web`.
- Inspect the current stack before assuming framework, database, auth, deployment, billing, analytics, or AI-provider choices.
- Keep changes small, phased, and verified.
- Do not push, deploy, send emails, or make external side-effect changes unless Louie explicitly approves.

## Technical Stack

- **Framework**: TanStack Start (React 19, TanStack Router, Nitro).
- **Styling**: Tailwind CSS v4.
- **Build Tool**: Vite.
- **Package Manager**: Bun/npm.
- **Database**: Local System PostgreSQL (Port 5432).

## Verification

Before calling technical work complete, run the relevant checks:

- `npm run build` (Production build success).
- `npm run lint` (No linting errors).
- Browser verification for visual/functional changes.
- Migration checks for database changes.

If a command cannot be run, explain why and what should be checked manually.

## Lovable Synchronization

- This project is connected to Lovable.
- Do not push to `main` or modify Git history (rebasing/amending/squashing) as it disrupts the Lovable synchronization.
- All changes must be verified locally before being pushed to the connected branch.

## Final Response Format

Use concise shipped-change summaries with:

1. What changed
2. Files changed
3. Commands run / verification result
4. Risks or notes
5. Deployment or migration handoff, if relevant
6. Recommended next step
